========================================
  项目运行说明
  基于大数据的淘宝用户行为分析可视化
========================================

一、项目运行环境
-------------------
操作系统：Windows / macOS / Linux（推荐 Windows）
开发环境：PyCharm（推荐）或其他 Python IDE
运行方式：本地 Web 服务

二、Python 版本
-------------------
Python 3.9 ~ 3.12（本项目基于 Python 3.10 开发）

三、依赖库
-------------------
运行项目前，请先安装以下 Python 依赖库：

  Flask==3.1.3          Web 后端框架
  pandas==2.3.3         数据处理与分析
  numpy==2.2.6          数值计算

安装命令：
  pip install flask pandas numpy

四、数据库配置方式
-------------------
本项目不使用传统关系数据库，数据采用 CSV 文件存储。
数据集文件存放在项目根目录下的"数据集"文件夹中，包含：
  - user_behaviors.csv   用户行为数据
  - orders.csv           订单数据
  - products.csv         商品数据
  - user_features.csv    用户特征数据

系统启动时会自动从"数据集"目录加载 CSV 文件，无需额外的数据库安装配置。

五、系统启动方式
-------------------
方式一：终端命令行启动
  1. 打开终端（CMD / PowerShell / Terminal）
  2. 进入项目根目录
  3. 执行命令：python app.py
  4. 在浏览器中访问 http://localhost:5000/

方式二：PyCharm 启动
  1. 使用 PyCharm 打开项目根目录
  2. 打开 app.py 文件
  3. 右键点击编辑区域，选择 "Run app.py"
  4. 在浏览器中访问 http://localhost:5000/

启动成功后，终端将显示：
  请访问: http://localhost:5000/
  * Running on http://127.0.0.1:5000

六、注意事项
-------------------
1. 确保"数据集"文件夹中的 CSV 文件完整且编码为 UTF-8 或 GBK
2. 首次运行前先安装所需依赖库
3. 建议使用 Python 虚拟环境（conda 或 venv）管理依赖
4. Flask 默认使用 5000 端口，如被占用可在 app.py 中修改 port 参数
5. 局域网内可通过本机 IP 访问（如 http://192.168.x.x:5000）
6. 前端 ECharts 图表通过 CDN 加载，需保持网络畅通
7. bg 文件夹中的背景图片请勿删除或移动
8. 如遇数据加载异常，请检查 CSV 文件列名是否与代码中一致

八、常见问题
-------------------
Q: 启动时提示 "ModuleNotFoundError: No module named 'flask'"
A: 请先执行 pip install flask pandas numpy

Q: 浏览器打开后页面空白或数据不显示
A: 检查终端输出是否有错误信息，确认 CSV 数据文件路径是否正确

Q: 端口被占用
A: 修改 app.py 最后一行 port 参数，如 port=5001
   然后访问 http://localhost:5001/

Q: 图片不显示
A: 确认 bg 文件夹中存在对应的图片文件，且 Flask 服务已正确启动
